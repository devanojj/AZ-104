- Azure Queue Storage — Simple message queue for storing messages until a worker processes them.

- Azure Service Bus — Enterprise messaging service with advanced features for reliable communication between applications.


| If the question mentions…                      | Choose        |     |
| ---------------------------------------------- | ------------- | --- |
| Simple, inexpensive queue for background tasks | Queue Storage |     |
| Topics and subscriptions                       | Service Bus   |     |
| Built-in dead-letter queue (DLQ)               | Service Bus   |     |
| Duplicate message detection                    | Service Bus   |     |
| Sessions for ordered processing                | Service Bus   |     |
| Enterprise application integration             | Service Bus   |     |
| Large volumes of simple messages               | Queue Storage |     |
