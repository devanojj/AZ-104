### Microsoft Azure Backup Server (MABS)
Backup on-premises server / workloads to an Azure Recovery Service (onto the cloud). More complex workloads


### Microsoft Azure Site Recovery Provider 
Used with Azure Site Recovery to co-ordinate recovery. It is not a backup tool (but instead support)


### Azure Connected Machine Agent
Connects to non-azure machine to Azure Arc. Monitor servers not in Azure
Can be used with on premises servers


### Microsoft Azure Recovery Services Agent
Back up files directly from Windows onto Azure Recovery, unlike MABS don't need a separate backup server. For files / folder / system state
