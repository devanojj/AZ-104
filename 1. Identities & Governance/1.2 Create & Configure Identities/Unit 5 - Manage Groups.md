==**Security groups**== 
Includes users, devices, and service principals. For example, you can create a security group for a specific security policy. 

==**Microsoft 365 groups**==  
Members access to a shared mailbox, calendar, files, SharePoint site, and more. This option also lets you give people outside of your organisation access to the group. This option is available to users and admins.


==**Membership Type**==
- **Assigned** - members are added and maintained manually.
- **Dynamic User** - users are added and removed automatically based on rules that evaluate user attributes such as department, job title, or location.
- **Dynamic Device** - devices are added and removed automatically based on rules that evaluate device attributes. Applies to security groups only; Microsoft 365 groups support dynamic users but not dynamic devices.

Dynamic membership requires a P1 license (or Intune for Education for device-based rules).
