*Application logging (Blob)*
This records **messages generated by your application**.
Useful to retain logs for longer periods. Persistent storage

*Application logging (FileSystem)*
This also records **application-generated logs**, but stores them on the App Service's **file system**. Local App Service storage.

*Detailed Error Messages*
This provides **detailed information about errors** that occur in your web application.

*Severity Levels*
Verbose - Information - Warning - Error - Critical 
If you configure warning, you also get error & critical 

You must enable the Application Logging (Blob) diagnostic, which can be stored for more than a week. You must also set the severity level to warning, to store warning, error, and critical log messages.
